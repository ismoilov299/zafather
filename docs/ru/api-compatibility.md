# Совместимость с Bot API

Zafather объявляет поддерживаемый уровень Telegram Bot API через
`BOT_API_VERSION`, а layer схемы MTProto — через
`zafather.mtproto.schema_layer()`.

| Zafather | Bot API | MTProto layer | Статус |
|---|---:|---:|---|
| 0.5.0 | 10.3 | 229 | Текущая |
| 0.4.2 | 10.2 | экспериментально | Опубликовано |
| 0.4.1 | 10.2 | — | Опубликовано |

## Правила для 10.3

- Ephemeral-сообщения отправляются через `ephemeral_message_parameters`.
- Rich draft-потоки всегда отправляют `draft_id`.
- Update `stopped_message_generation` принимается через router.

## Методы без обертки

Любой метод Bot API можно вызвать еще до того, как в Zafather появится помощник:
`await bot.bot.any_method_name(chat_id=..., ...)` превращает имя `snake_case` в
`camelCase` и сериализует аргументы. Поля, точное имя которых не закреплено в
официальной документации, не зашиваются в код, а передаются через `**params`.

## Обновление схемы MTProto

Схема TL поставляется вместе с пакетом (`zafather/mtproto/tl/data/api.tl`) и
читается во время работы, поэтому генерация кода не нужна. Чтобы перейти на
новый layer, замените этот файл официальной схемой (сохранив строку
`// LAYER N`), обновите ожидаемый layer в `tests/mtproto/test_tl.py` и запустите
тесты; они также проверяют, что ID каждого конструктора совпадает с CRC32 его
объявления.
